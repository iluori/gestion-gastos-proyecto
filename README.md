# gestion-gastos-proyecto
Proyecto personal para aprender y practicar conceptos de programación mediante una aplicación de gestión de gastos. En desarrollo y actualizándose de forma incremental.

## Objetivo

Crear una aplicación que permita a un usuario registrar y consultar sus gastos personales, organizarlos mediante categorías y obtener un resumen de sus gastos a lo largo del tiempo.

El proyecto se desarrollará progresivamente, empezando por una versión sencilla y añadiendo funcionalidades a medida que avance.
